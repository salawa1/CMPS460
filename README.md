## Reflection

The app requests permission from the user to use the camera and location services. If the user denies camera permission, the app displays a message explaining that access can be enabled in settings, and nothing shows up on the camera viewfinder. If location permission is denied, the app displays a similar message and terminates the process of requesting coordinates. Denying one permission doesn't prevent the other permission from being accessed. Location and camera is only requested when the user presses the button(s).
